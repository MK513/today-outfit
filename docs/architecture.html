오늘 뭐 입지 (Today Outfit) Architecture

Vue 3 + Pinia 클라이언트 전용 SPA · localStorage 영속화 · AI 목업 · 하단은 명세만 있는 백엔드 계획

현재 구조: 클라이언트 전용

  • • Vue 3.5 + Vite 8 SPA, 서버 호출 없음
  • • Pinia store 5개가 상태와 비즈니스 규칙을 담당
  • • 4개 store는 localStorage에 저장, challenge는 메모리 전용
  • • 의류 삭제 → 코디에서 참조 제거, 코디 삭제 → 플래너 일정 삭제

AI 기능 (목업)

  • • 사진 분석 · 문장 파싱 · 코디 추천 · 주간 추천 · 챌린지 평가
  • • setTimeout 지연과 무작위 실패로 로딩/에러 UI를 재현
  • • 실사 사진이 매칭되는 의류만 코디 후보로 사용
  • • 결과는 후보일 뿐, 사용자가 확인해야 store에 저장

백엔드 전환 계획

  • • API 명세: 23개 경로, JWT Bearer 인증
  • • DB 명세: 7개 테이블 (ai_requests로 AI 호출 기록)
  • • store 액션을 fetch 호출로, mockAi를 /ai/**로 교체
  • • 현재 비밀번호가 평문으로 localStorage에 저장됨 → 서버 해싱 필요
